# Raw data

Raw RNA-seq data are not redistributed in this repository.

Public source datasets:

- GSE152641 — severe COVID-19 and healthy controls
- GSE196399 — severe non-COVID-19 pneumonia and healthy controls

Place raw gene-count matrices here using the filenames configured in `R/config.R`.
Gene symbols should be row names (or the first column, which the helper loader can convert).
